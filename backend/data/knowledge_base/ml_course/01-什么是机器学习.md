# 01 · 什么是机器学习

## 学习目标
- 区分机器学习与传统程序设计的根本差异
- 掌握机器学习三大基本范式:监督学习、无监督学习、强化学习
- 理解一个完整机器学习项目的流程

## 核心概念

机器学习是人工智能的一个分支,它让计算机**从数据中自动学习规律**,而不是像传统程序那样由人手工编写每条规则。核心区别在于:传统程序是"规则 + 数据 → 答案",机器学习是"数据 + 答案 → 规则"。

### 三大范式

1. **监督学习(Supervised Learning)**:训练数据带有正确答案(标签)。模型学习"输入 → 输出"的映射。
   - 分类(Classification):预测离散类别,如判断邮件是否为垃圾邮件、图像中是猫还是狗。
   - 回归(Regression):预测连续数值,如房价、气温、销售额。
2. **无监督学习(Unsupervised Learning)**:训练数据没有标签,模型自己发现结构。
   - 聚类(Clustering):把相似样本分到一组,如客户分群。
   - 降维(Dimensionality Reduction):压缩特征数量但保留信息,如 PCA。
3. **强化学习(Reinforcement Learning)**:智能体通过与环境交互获得奖励信号,学习最大化长期回报的策略。典型应用:游戏 AI、机器人控制、AlphaGo。

### 完整项目流程

1. **问题定义**:明确是分类、回归还是聚类,定义评价指标。
2. **数据收集与清洗**:处理缺失值、异常值、重复数据。
3. **特征工程**:选择、构造、转换特征(这是实践中耗时最多的环节)。
4. **数据划分**:通常按 7:2:1 或 8:2 划分训练集/验证集/测试集。
5. **模型选择与训练**:根据问题类型和数据规模选择合适模型。
6. **评估与调优**:用验证集调整超参数,防止过拟合。
7. **部署与监控**:上线后持续监控模型表现,必要时重训。

```python

from sklearn.model_selection import train_test_split
```

## 易错点
- **数据泄漏**:测试集信息混入训练过程(如先全量标准化再划分),导致评估虚高。
- **盲目追求准确率**:类别不平衡时(如 99% 负样本),准确率会骗人,要看精确率/召回率/F1。
- **忽略业务目标**:模型指标好 ≠ 业务效果好。
