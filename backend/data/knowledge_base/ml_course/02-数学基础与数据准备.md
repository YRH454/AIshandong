# 02 · 数学基础与数据准备

## 学习目标
- 建立概率、向量、梯度三大数学工具在机器学习中的直觉
- 掌握特征工程的基本方法
- 理解数据划分与数据泄漏的陷阱

## 核心概念

### 概率与贝叶斯思想
概率描述不确定性。机器学习中常见:
- **条件概率** P(A|B):已知 B 发生后 A 的概率,是朴素贝叶斯分类器的基础。
- **贝叶斯定理**:P(A|B) = P(B|A)P(A) / P(B)。它回答"根据新证据更新信念"的问题。
- **似然**:在参数给定的前提下观察到数据的概率,极大似然估计(最大化似然)是很多模型的训练原理。

### 向量与矩阵
每个样本通常表示为一个特征向量。例如一个学生样本 `[学时, 基础测验分, 作业完成率]`。向量的**点积**衡量相似度,是线性模型 y = w·x + b 的核心。矩阵是多个样本的集合(行=样本,列=特征)。

### 梯度(Gradient)
梯度是多元函数在某点对每个变量求偏导后组成的向量,指向**函数上升最快的方向**。所以梯度下降沿负梯度方向更新参数就能最小化损失。直观理解:站在山坡上,沿着最陡的下降方向走,就能更快到谷底。

### 特征工程
- **缺失值处理**:数值列用均值/中位数填充,类别列用众数填充或删除。
- **标准化(Standardization)**:x' = (x - mean) / std,让特征均值0方差1,对梯度下降收敛很重要。
- **归一化(Normalization)**:缩放到[0,1],适合有界特征。
- **独热编码(One-Hot)**:把类别特征(如"红/绿/蓝")转成 0/1 向量,避免给类别强加数值顺序。
- **特征选择**:剔除冗余/低相关特征,降低过拟合风险。

### 数据划分与数据泄漏
标准划分:训练集(拟合模型)、验证集(调超参)、测试集(最终评估)。
**数据泄漏**是新手最常见的致命错误:在划分数据**之前**就做标准化/填补(用了测试集信息)、或让训练时看到未来信息,都会让验证分数虚高、上线就崩。

## 代码示例
```python
import numpy as np
from sklearn.preprocessing import StandardScaler

X = np.array([[170, 60], [180, 75], [160, 50]])  # 身高体重
scaler = StandardScaler()
# 先 fit 训练集,再 transform 训练/测试集 —— 避免数据泄漏
X_train_scaled = scaler.fit_transform(X[:2])
X_test_scaled = scaler.transform(X[2:])
```

## 易错点
- 用全量数据算 mean/std 再划分 → 数据泄漏。
- 类别特征直接用数字编码(红=1,绿=2)→ 模型误以为有大小关系。
- 忘记标准化就做梯度下降 → 收敛慢甚至发散。

## 自测题
1. 梯度指向函数值______的方向。答案:上升最快。
2. 为什么标准化能加速梯度下降?答案:特征量纲一致后,损失函数等高线更接近圆形,参数更新更均匀。
3. 数据泄漏会带来什么后果?答案:验证/测试分数虚高,实际部署时模型失效。
