# 03 · 监督学习模型

## 学习目标
- 掌握线性回归、逻辑回归、决策树、KNN、朴素贝叶斯五个经典监督学习模型
- 理解每个模型的适用场景与假设

## 核心概念

### 线性回归(Linear Regression)
拟合 y = w·x + b,使预测与真实值的均方误差(MSE)最小。适合连续数值预测(回归)。假设特征与目标近似线性关系。

### 逻辑回归(Logistic Regression)
名字带"回归"但实际是**分类**模型。它把线性组合 z = w·x + b 通过 Sigmoid 函数 σ(z) = 1/(1+e^-z) 压缩到 (0,1),输出作为"属于正类"的概率。用交叉熵损失训练。是二分类的强基线。

### 决策树(Decision Tree)
通过一系列"如果-那么"规则划分数据。每次选择一个特征和阈值,使划分后子集"纯度"最高(常用信息增益或基尼不纯度)。优点:可解释性强;缺点:容易过拟合,需剪枝或限制深度。

### K 近邻(KNN)
不训练参数,直接存储训练样本。预测时找离新样本最近的 K 个已知样本,投票决定类别(或平均得到回归值)。K 越小越容易过拟合。距离度量常用欧氏距离。缺点:高维数据距离度量失效("维度灾难")。

### 朴素贝叶斯(Naive Bayes)
基于贝叶斯定理,并假设特征**条件独立**("朴素"即此意,尽管现实中常不成立)。对文本分类(垃圾邮件过滤)非常高效。计算简单、训练快。

## 模型选择速查
| 问题 | 推荐起点 |
|------|----------|
| 连续数值预测 | 线性回归 |
| 二分类 | 逻辑回归 |
| 需要可解释的规则 | 决策树 |
| 小规模、特征少 | KNN |
| 文本/高维稀疏 | 朴素贝叶斯 |

## 易错点
- 用线性回归做分类(输出无界、不适合概率解释)。
- 决策树不设深度限制 → 完全过拟合到训练集。
- KNN 的 K 选太大 → 决策边界过于平滑,欠拟合。
- 特征量纲差异大时不标准化 → KNN 的欧氏距离被大数值特征主导。

## 自测题
1. 逻辑回归是回归模型还是分类模型?答案:分类模型。
2. 决策树过拟合时最直接的两个对策?答案:限制最大深度、剪枝、增大最小样本数。
3. 为什么 KNN 对特征标准化敏感?答案:距离计算时大数值特征会主导欧氏距离。
