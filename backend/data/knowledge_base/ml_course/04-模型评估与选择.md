# 04 · 模型评估与选择

## 学习目标
- 掌握混淆矩阵与精确率、召回率、F1、AUC 等核心指标
- 理解偏差-方差权衡与交叉验证
- 学会在类别不平衡时正确评估模型

## 核心概念

### 混淆矩阵(Confusion Matrix)
二分类的四种结果:
- **TP** 真正例:预测正、实际正
- **FP** 假正例:预测正、实际负(误报)
- **TN** 真负例:预测负、实际负
- **FN** 假负例:预测负、实际正(漏报)

### 关键指标
- **准确率 Accuracy** = (TP+TN)/全部。类别不平衡时不可靠(99% 负样本时全预测负也有 99% 准确率)。
- **精确率 Precision** = TP/(TP+FP)。预测为正的里面有多少是对的。"宁缺毋滥"。
- **召回率 Recall** = TP/(TP+FN)。实际为正的里面抓到多少。"宁滥勿缺"。
- **F1** = 2·Precision·Recall/(Precision+Recall)。精确率与召回率的调和平均,平衡两者。
- **AUC** = ROC 曲线下面积。衡量模型把所有正样本排在负样本前面的能力,越接近 1 越好,对类别不平衡稳健。

### 精确率 vs 召回率的取舍
- 垃圾邮件过滤:更看重精确率(别把正常邮件误杀)。
- 癌症筛查:更看重召回率(别漏掉病人,宁可多查)。

### 偏差-方差权衡(Bias-Variance Tradeoff)
- **高偏差** = 欠拟合:模型太简单,训练集和测试集都差。
- **高方差** = 过拟合:模型太复杂,训练集好但测试集差。
- 调参就是在两者间找平衡:增加复杂度降偏差但升方差,反之亦然。

### 交叉验证(Cross Validation)
把训练集切成 K 折,轮流用 K-1 折训练、1 折验证,K 次后取平均。比单次划分更稳定地估计泛化能力。常用 K=5 或 10。**注意:交叉验证内部每一折都要重新做标准化,防止数据泄漏。**

## 代码示例
```python
from sklearn.model_selection import cross_val_score
from sklearn.metrics import classification_report, roc_auc_score
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(n_estimators=100)
scores = cross_val_score(model, X, y, cv=5)
print("交叉验证平均:", scores.mean())

model.fit(X_train, y_train)
print(classification_report(y_test, model.predict(X_test)))
print("AUC:", roc_auc_score(y_test, model.predict_proba(X_test)[:, 1]))
```

## 易错点
- 类别不平衡只看准确率 → 被假象欺骗。
- 只用训练集评估 → 过拟合模型"自我感觉良好"。
- K 折交叉验证时每折忘记标准化 → 泄漏。

## 自测题
1. 癌症筛查应优先保证哪个指标?答案:召回率(不漏诊)。
2. 模型在训练集 99% 准确率、测试集 70%,说明什么?答案:过拟合(高方差)。
3. F1 分数解决了什么问题?答案:在类别不平衡时综合精确率与召回率,避免准确率的假象。
