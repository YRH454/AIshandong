# 05 · 梯度下降与优化

## 学习目标
- 理解损失函数、梯度下降的数学直觉
- 掌握 SGD、Mini-batch、学习率、收敛等核心概念
- 认识动量与 Adam 等改进优化器

## 核心概念

### 损失函数(Loss Function)
衡量模型预测与真实值的差距,是优化的目标。常见:
- 均方误差 MSE(回归)
- 交叉熵(分类)
模型训练 = 找到使损失最小的参数。

### 梯度下降(Gradient Descent)
沿损失函数负梯度方向迭代更新参数:
- 参数更新:θ = θ - η·∇L(θ),其中 η 是**学习率**,∇L 是损失对参数的梯度。
- 学习率太大:参数在谷底来回震荡甚至发散;太小:收敛极慢。

### 三种变体
1. **批量梯度下降(BGD)**:用全部样本算梯度。准确但慢,大数据集内存吃紧。
2. **随机梯度下降(SGD)**:每次只用一个样本更新。快、能跳出局部极小,但噪声大。
3. **Mini-batch SGD**:每次用一小批(如 32/64/128)样本。兼顾速度与稳定,是实践中默认选择。

### 收敛与学习率调度
- 收敛意味着损失趋于稳定。可通过绘制损失曲线判断。
- **学习率衰减**:训练后期调小学习率帮助收敛。
- 监控:损失不再下降 = 该调学习率了;在测试集上升 = 过拟合,不是优化器问题。

### 改进优化器
- **动量(Momentum)**:累积历史梯度方向,加速收敛、减少震荡。
- **Adam**:结合动量与自适应学习率(RMSProp 思想),是深度学习的默认优化器,几乎不用调参。

## 代码示例
```python
import numpy as np

def gradient_descent(X, y, lr=0.01, epochs=100, batch_size=32):
    m, n = X.shape
    w = np.zeros(n)
    for epoch in range(epochs):
        idx = np.random.permutation(m)
        for i in range(0, m, batch_size):
            batch = idx[i:i + batch_size]
            Xb, yb = X[batch], y[batch]
            grad = Xb.T @ (Xb @ w - yb) / len(batch)  # MSE 梯度
            w -= lr * grad
    return w
```

## 易错点
- 学习率设太大,损失曲线直接发散(NaN)。
- 特征未标准化 → 梯度方向被大数值特征带偏,收敛慢。
- 把"训练损失高"归因于优化器,实际是模型容量不够(欠拟合)或特征有问题。

## 自测题
1. 学习率过大会导致什么?答案:震荡、发散,损失不降反升。
2. Mini-batch 的 batch size 一般取多少?答案:32-256,常用 32/64/128。
3. 深度学习中默认最常用的优化器是?答案:Adam。
