## 学习目标
- 理解感知机、激活函数与多层感知机
- 掌握反向传播的核心思想
- 认识 CNN 与 RNN 两大架构的适用场景

## 核心概念

### 从感知机到神经网络
**感知机(Perceptron)** 是单层线性单元,只能解决线性可分问题。**多层感知机(MLP)** 在输入与输出之间加隐藏层,并用非线性激活函数,就能逼近任意函数(万能逼近定理)。深度 = 多层,深度学习即"很深的 MLP 的现代化身"。

### 激活函数
- **ReLU** = max(0, x):计算快、缓解梯度消失,隐藏层默认选择。
- **Sigmoid**:输出(0,1),适合输出概率;但两端梯度接近 0,易梯度消失。
- **Tanh**:(-1,1),比 Sigmoid 好一点。
- **Softmax**:多分类输出层,把分数转成概率分布。

### 反向传播(Backpropagation)
用**链式法则**从输出层向输入层逐层计算损失对每个参数的梯度,配合梯度下降更新。关键直觉:误差从输出反向传播,每层都知道"自己该往哪调"。

### CNN(卷积神经网络)
专为图像设计。核心操作:
- **卷积层**:用卷积核提取局部特征(边缘、纹理)。
- **池化层**:下采样缩小尺寸(最大池化保留最显著特征)。
- **全连接层**:把特征映射到类别。
**权值共享**让参数量远小于全连接,配合平移不变性,是图像识别的基础。

### RNN(循环神经网络)
处理序列数据(文本、语音、时间序列)。关键:隐藏状态 h 在时间步间传递,保留"记忆"。短板是长序列梯度消失/爆炸;改进方案是 **LSTM** 和 **GRU**(引入门控机制选择性记忆与遗忘)。

## 代码示例
```python
from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    layers.Dense(64, activation='relu', input_shape=(X.shape[1],)),
    layers.Dense(32, activation='relu'),
    layers.Dense(1, activation='sigmoid'),  # 二分类
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
model.fit(X_train, y_train, epochs=10, batch_size=32, validation_split=0.2)
```

## 易错点
- 隐藏层全用 Sigmoid → 深度网络梯度消失,训不动。
- 忘记标准化输入 → 神经网络收敛极慢。
- 类别不平衡时只看 accuracy → 被假象骗。
- 数据量小却用超大网络 → 严重过拟合。

## 自测题
1. 为什么深度网络需要非线性激活函数?答案:没有非线性,多层线性变换叠加仍是线性,等价于单层,无法表达复杂函数。
2. CNN 两大核心设计是什么?答案:卷积(局部感受野+权值共享)与池化(下采样)。
3. RNN 长序列效果差的原因及改进?答案:梯度消失/爆炸;用 LSTM/GRU 门控机制。
