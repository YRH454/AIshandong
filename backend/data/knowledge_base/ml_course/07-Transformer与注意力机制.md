# 07 · Transformer 与注意力机制

## 学习目标
- 理解自注意力机制的核心思想
- 掌握 Q、K、V 与多头注意力的概念
- 认识 Transformer 如何成为 BERT、GPT 等大模型的基础

## 核心概念

### 为什么需要注意力
RNN 按顺序处理序列,长距离信息要靠隐藏状态一步步传递,容易丢失。**注意力机制(Attention)** 让每个词**直接关注**序列中所有其他词,一步建立全局依赖。

### 自注意力(Self-Attention)
对输入序列的每个词,计算它与所有词的"相关性权重",再按权重加权求和得到新表示。流程:
1. 每个词生成三个向量:**Query(Q)**、**Key(K)**、**Value(V)**。
2. 计算 Q 与所有 K 的点积,除以根号 d(缩放防梯度爆炸),过 Softmax 得到注意力权重。
3. 用权重对 V 加权求和,得到该词的上下文表示。
直观理解:Q 是"我在找什么",K 是"我有什么标签",V 是"我携带的内容"。

### 多头注意力(Multi-Head Attention)
把 Q/K/V 投影到多组(8 或 16 组)子空间,并行算多份注意力,拼接后融合。不同头可以关注不同类型的依赖(语法关系、指代、语义),提升表达能力。

### 位置编码(Positional Encoding)
自注意力本身**不感知词序**(对集合的操作),所以需要加入位置信息。Transformer 用正弦/余弦函数生成位置编码加到词向量上。

### Transformer 整体架构
- **编码器(Encoder)**:多头自注意力 + 前馈网络,理解输入。
- **解码器(Decoder)**:掩码自注意力 + 交叉注意力 + 前馈网络,生成输出。
- **BERT** 用编码器做双向理解(适合分类、抽取)。**GPT** 用解码器做自回归生成(适合文本生成)。

## 注意力公式
注意力分数 = softmax( Q·Kᵀ / √d ) · V
其中 d 是向量维度,√d 用于缩放。

## 代码示例(伪代码)
```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V):
    d = Q.shape[-1]
    scores = Q @ K.transpose(-2, -1) / (d ** 0.5)   # [batch, heads, len, len]
    weights = F.softmax(scores, dim=-1)
    return weights @ V
```

## 易错点
- 忽略位置编码 → 模型把"猫追狗"和"狗追猫"当一样。
- 忘记缩放(÷√d)→ 点积过大,Softmax 进入饱和区,梯度消失。
- 把 BERT/GPT 混为一谈:BERT 双向编码适合理解,GPT 单向自回归适合生成。

## 自测题
1. Q、K、V 分别代表什么?答案:Q=查询(我要找什么),K=键(内容的标签),V=值(实际内容)。
2. 为什么需要多头注意力?答案:不同头关注不同类型的依赖,提升表达能力。
3. 自注意力为什么需要位置编码?答案:注意力本身是排列不变的,不加入位置编码就丢失词序信息。
