# 08 · 无监督学习与强化学习

## 学习目标
- 掌握 KMeans 聚类与 PCA 降维的原理与用法
- 理解强化学习的状态、动作、奖励、策略四要素
- 认识 Q-Learning 的基本思想

## 核心概念

### KMeans 聚类
把样本分成 K 组,组内相似、组间相异。算法流程:
1. 随机选 K 个质心。
2. 把每个样本分到最近的质心。
3. 用每组的均值更新质心。
4. 重复 2-3 直到质心不再变化。

**选择 K**:肘部法(画"K - 组内平方和"曲线找拐点)或轮廓系数。
**局限**:K 要提前指定;对离群点敏感;聚类结果依赖初始质心(可多次随机重启)。

### PCA 主成分分析
一种线性降维方法。思想:找数据方差最大的若干正交方向(主成分),把高维数据投影到这些方向,保留大部分信息。
- 做法:对数据做标准化 → 计算协方差矩阵 → 特征分解 → 取前 k 个最大特征值对应的特征向量。
- 用途:降维可视化、去除冗余特征、加速训练、缓解维度灾难。
- 注意:PCA 是线性方法,无法捕捉非线性结构(可用 t-SNE/UMAP 补充)。

### 强化学习四要素
1. **状态(State)**:智能体当前所处环境情况。
2. **动作(Action)**:智能体可执行的选择。
3. **奖励(Reward)**:环境对动作的即时反馈(可正可负)。
4. **策略(Policy)**:状态到动作的映射,是学习的目标。

核心目标:**最大化长期累积奖励**(考虑折扣因子 γ,未来奖励打折扣)。

### Q-Learning
维护一张 Q 表,Q(s, a) 表示"在状态 s 采取动作 a 的长期期望收益"。
更新公式(贝尔曼方程):
Q(s,a) ← Q(s,a) + α·[r + γ·max Q(s', a') − Q(s,a)]
其中 α 是学习率,r 是即时奖励,s' 是下一个状态。通过不断试错更新 Q 表,最终收敛到最优策略。

**探索 vs 利用(Exploration vs Exploitation)**:既要尝试新动作(探索)也要利用已知好的动作(利用),常用 ε-贪心策略。

## 代码示例
```python
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA

# KMeans 聚类
kmeans = KMeans(n_clusters=3, n_init=10, random_state=42).fit(X)
print("簇标签:", kmeans.labels_)

# PCA 降维到 2 维可视化
pca = PCA(n_components=2)
X_2d = pca.fit_transform(X)
```

## 易错点
- 用 PCA 前不标准化 → 大数值特征主导主成分。
- 聚类结果直接当"真实标签" → 聚类是发现结构,不等同于监督分类。
- 强化学习里设 γ 太大/太小 → 太看重未来会忽视即时反馈,太小则短视。

## 自测题
1. 肘部法用来做什么?答案:确定 KMeans 的最佳簇数 K。
2. PCA 的核心目标是什么?答案:找到方差最大的正交方向,降维同时保留主要信息。
3. Q-Learning 的 Q(s,a) 表示什么?答案:状态 s 下采取动作 a 的长期期望累积收益。
