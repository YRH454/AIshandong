# 学境平台 — 默认知识库

## 学习理论

### 费曼学习法
费曼学习法是一种以教代学的学习方法，核心理念是：如果你不能用简单的语言解释一个概念，说明你还没有真正理解它。
步骤：
1. 选择一个要学习的概念
2. 尝试用最简单的话向一个"不懂的人"解释
3. 发现解释不清的地方，回到资料中重新学习
4. 简化语言，用类比帮助理解

### 布鲁姆分类法（Bloom's Taxonomy）
布鲁姆将认知学习目标分为六个层次（从低到高）：
1. 记忆 — 回忆事实和基本概念
2. 理解 — 用自己的话解释概念
3. 应用 — 在新情境中使用知识
4. 分析 — 把信息分成部分并找出关系
5. 评价 — 基于标准做出判断
6. 创造 — 生成新的想法或作品

### 间隔重复（Spaced Repetition）
间隔重复是一种基于遗忘曲线的记忆技术：在即将遗忘的时间点进行复习，效率最高。
典型间隔：1天 → 3天 → 7天 → 14天 → 30天 → 90天

## 常见学习问题

### 如何克服拖延症？
1. 2分钟法则：如果任务可以在2分钟内完成，立即做
2. 番茄工作法：25分钟专注 + 5分钟休息
3. 拆解大任务：把大目标分解成多个小步骤
4. 公开承诺：告诉他人你的计划，增加外部压力

### 如何提高学习效率？
1. 主动回忆：合上书本，尝试回忆学过的内容
2. 交替练习：交替学习不同主题，而非死磕一个
3. 自我提问：学习时不断问自己"为什么"和"怎么做"
4. 教给别人：用费曼技巧检验理解程度

### 如何选择学习资源？
1. 优先教材和官方文档
2. 视频适合入门，文档适合深入
3. 动手实践 > 被动阅读
4. 及时整理笔记，建立知识之间的联系
