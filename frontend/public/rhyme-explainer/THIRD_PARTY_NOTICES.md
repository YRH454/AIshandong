# RHYME interactive explainer — third-party notices

This directory contains an adapted local copy of **The Wisdom and/or Madness of Crowds** by Nicky Case. The original work is dedicated to the public domain under **CC0 1.0**; its copy is included as `LICENSE-crowds-CC0.txt`.

The interaction structure, hand-drawn UI, simulation code, sprites, and the RHYME adaptation are served locally from this directory. RHYME's learning narrative and copy were written separately for this product.
